
cette solution peut aider l'opérateur Eneo à résoudre les problèmes de relevés d'index grâce aux compteurs intelligents
réduisant ainsi le nombre d'employés pour une optimisation des ressources sur le long terme







technologies:
frontend: react
backend: node.js
blockchain: solidity

fonctionnalités:

ajouter un compteur
assigner un compteur
désassigner un compteur
authentification
simulation compteurs intelligents
consulter consommation en temps réel
consulter historique de consommation par jour, mois, année
vérifier facture
soumettre une réclamation
traiter une réclamation
résoudre/rejeter une réclamation
génération mensuelle automatique de factures
regénérer  une facture après réclamation,
détection automatique d'anomalies
alertes




installation:


cloner: git clone url_repository

backend:
npm install
node index.js

frontend:
npm install
npm run dev
